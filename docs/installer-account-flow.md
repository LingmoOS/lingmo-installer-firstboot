# 安装与首次启动的账户交接

安装流程：欢迎 → 地区与时区 → 软件选择 → 分区 → 创建用户 → 摘要 → 安装 → 完成。

安装器在解包后执行 locale、localecfg、users、displaymanager，将选择的时区、语言及用户写入目标系统。displaymanager 配置只指定 lingmo-dm。

Lingmo DM 模块记录安装用户及自动登录选择到 /etc/lingmo-oobe-account.conf（root 可读写）。首次启动使用该账户临时自动登录 lingmo-oobe；不再查找“第一个普通用户”，也不创建临时 lingmo 用户或解锁密码。

当前 OOBE 界面已经只有欢迎、主机名、应用设置和完成，没有创建用户页。完成程序在提权后读取账户记录，保留显示管理器其他配置，将会话切回 lingmo-wayland。若安装时关闭自动登录，则清空自动登录用户名，之后显示登录界面。仅配置成功才写入完成标记；失败允许重试，不展示虚假的完成状态。

旧镜像没有安装账户记录时，首次启动服务明确失败，不擅自创建或选择账户。此改动需安装器、安装配置、OOBE 三个包一起交付。安装用户与时区的完整端到端效果仍需使用新镜像在虚拟机安装验收。
